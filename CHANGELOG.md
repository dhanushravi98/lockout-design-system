# Changelog

Each entry says what an app has to do: **visual only** means the app only needs the new `tokens.css`; **needs code changes** means component code must change too.

## v0.1.0 (2026-10-02)
First release. **Needs code changes** (everything is new).

- Tokens: blue (brand #25395C), neutral, red, amber, and green shade scales, 50 to 950.
- Semantic tokens for light and dark mode: backgrounds, borders, text, actions, navigation, five statuses, shadows.
- Spacing (4px base, xs to 4xl), radii (sm 4, md 8, lg 12), control heights (28, 32, 40), type scale (12 to 32), weights (400, 500, 600), motion.
- Typeface: Google Sans Flex.
- Specs: button, input, badge, alert, table, navigation (web only).
- `components/reference.html`, `npm run build`, `npm run check`.
